# Research Connect

A mobile-first React and TypeScript prototype for the student and professor research-opportunity flows in the linked Figma design. It uses plain CSS and local demo state; no backend or account persistence is configured.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.

## Prototype flows

- Sign in as a student or professor, or create a student profile.
- Browse, search, sort, and open research opportunities; submit an application.
- Visit student and professor profiles and message the faculty contact.
- Open the professor dashboard, review applicants, save a draft, or publish a listing.

The app is designed around the Figma reference's 402 px mobile canvas and adapts to narrower and wider viewports.
